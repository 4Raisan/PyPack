# PyPack 0.1.1

- Add offline regression checks for command routing, package-operation failures, interpreter selection and OS-managed Python protection.
- Add automated checks on Windows, Linux and macOS with Python 3.10 and 3.14.
- Build standalone launchers from the current source, with the icon and MIT license included. Unix launchers preserve arguments and exit status and clean up their temporary files.
- Include a complete source ZIP and SHA256 checksums alongside the three application downloads.
- Keep generated downloads in GitHub Releases instead of the current source tree. Existing v0.1.0 downloads remain available.

The package-management interface is unchanged. Windows downloads remain unsigned. Linux/macOS require Python 3.10+ and tkinter; native GUI and clean-machine installation checks remain manual.
